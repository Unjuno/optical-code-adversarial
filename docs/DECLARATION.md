## 宣言と実装の差分（5 条）

1. **レポートの 142B 結果のラベル違い**: `RESEARCH_REPORT_JA.md` の hard 表は 846/1000 を「敵対的142B」と記載するが、
   `results/holdout_final_hard_advgraph142.csv` は 835/1000。846/1000 は `combined142`（敵対的グラフ＋ trained layout）の値で、
   README 側は正しく「敵対的グラフ＋配置」と書いている。レポートのラベルのみ不正確。
2. **比較条件の検出閾値が非対称**: `final_validation.py` の SCHEMES は base138/spare*/advgraph* に detection threshold 140、
   frame140_v01 に 160 を設定する。README の「同一カメラ条件・同一シード」という公平性宣言はこれを開示していない。
3. **設計選抜と評価モードの不一致**: `train.py` と `optimize_core_graph.py` は 142B（extra_bytes=4）のペイロードで
   配置・パリティグラフを選抜するが、最終的な「堅牢モード」は 140B（extra_bytes=2）。選抜条件と評価条件が異なる。
4. **補助 ECC の反復数が未宣言**: レポートは主 ECC を「最大 18 反復」（`CORE_MAX_ITER=18`）と明記するが、
   追加 37 セルの `decode_aux()` は既定 24 反復で、宣言に記載がない。
5. **実機・規格比較の証拠なし**: 「SOTA 未実証」「QR/JAB 未比較」は宣言どおり。実カメラ、ロールシャッター、ISP、
   逆光などの試験データはリポジトリに存在せず、99% 目標（D 判定 FAIL）も未達。
